# Responsive React Portfolio

A sleek, responsive, and animated portfolio website built using **React**, **Tailwind CSS**, and **Vite**. It highlights skills, showcases projects, and provides a smooth user experience with scroll-based animations and responsive design.

> **Live Demo:** [responsive-react-portfolio.netlify.app](https://responsive-react-portfolio.netlify.app)  
> **GitHub Repo:** [github.com/Gerges-GN/Responsive-React-Portfolio](https://github.com/Gerges-GN/Responsive-React-Portfolio)

---

## Tech Stack

- **React 18** – Component-based UI
- **Tailwind CSS** – Utility-first styling
- **Vite** – Fast frontend tooling
- **React Icons** – Scalable vector icons
- **React CountUp** – Animated number counters
- **AOS (Animate on Scroll)** – Scroll-triggered animations

---

## Features

- ✅ **Fully Responsive Layout**  
  Looks great on all screen sizes, from mobile to desktop.

- ✅ **Animated Scroll Effects**  
  Powered by AOS for a dynamic user experience.

- ✅ **Projects Section**  
  Showcases key projects with live demo and GitHub links.

- ✅ **Skills Display**  
  Clean layout of technologies and tools with animated counters.
